## ui

`ui/` 保存站点级 DOM 控件。当前主要实现是 `SiteShell.tsx`，负责固定顶部品牌入口、监控跳转、移动端菜单和页面滚动容器。

**Important:** `SiteShell` 由 `HomePage.tsx` 传入 `children` 和可选的 `onReturnHome`；Logo 仅展示品牌文字；不要把页面内容塞进壳层。

### Important files

- `SiteShell.tsx` — 站点外壳、品牌文字、返回主页按钮、监控链接、S 快捷键、移动端菜单和 `.site-scroll-root` 滚动容器。
- `PerformancePanel.tsx` — 保留的独立调试组件，当前站点壳不挂载；提供三项性能数值：FPS、绘制次数、纹理显存估算，订阅 `utils/scenePerformance.ts`，不重渲染整个页面。

### Implementation notes

- 背景音乐由 `AudioManager` 在首次用户操作时创建并播放，使用从 `public/bgm.mp3` 导入的 URL；S 键监听必须在组件卸载时清理。
- 桌面和移动端复用同一组控制，菜单状态只由壳层维护；滚动内容通过 `children` 注入。
- `onReturnHome` 存在时显示“返回[/]”，位于桌面导航最右侧、移动菜单最后一项。点击调用首页回调、收起菜单并将容器回顶；桌面焦点移至品牌文字，移动端回到菜单按钮，避免按钮消失后丢失焦点。壳层不直接修改相机或刷新页面。
- 顶部栏统一以 `901px` 为桌面起点；移动端菜单锚定在 44px 方形按钮下，图标限制在 24px 内，菜单项统一左对齐且触控高度至少 44px。面板使用导航语义，限制视口内的宽高并允许内部滚动。
- 每次进入走廊、返回按钮从不可用变为可用时，显示 5 秒灰绿色细框提示后淡出；依赖回调是否存在而不是回调引用，避免首页重渲染重启计时。提示不抢焦点、不拦截点击，减少动态效果时取消淡出过渡，离开或卸载时清理计时器。
- 移动端菜单支持按钮切换、点击外侧、焦点移出和 Esc 收起；Esc 将焦点还给菜单按钮。切到桌面时重置展开状态，避免返回窄屏后残留菜单；事件监听须清理。
- 修改顶部栏后验证 320px/390px 窄屏、横屏和 900px/901px 断点，确认无横向溢出、菜单项对齐、监控链接可用，并检查 Esc 与键盘焦点。
- 桌面导航和移动端菜单均不显示“旧版”链接。
- Logo 使用 `LBQ.WORKS` 品牌文字，不绑定跳转或回顶事件；Three.js 相机交互由场景组件负责。
- 修改站点滚动容器或音乐交互时，同步核对页面布局、`AudioProvider` 和对应静态资源。
- 壳层只保留品牌、返回主页控件、监控链接、S 快捷键、移动菜单和内容容器；不挂载空状态栏，也不监听无展示用途的时间或指针状态。

- 桌面和窄屏菜单仅提供“监控”业务入口（走廊中另有返回按钮），复用 `data/site.ts` 中“前端监控”的公开地址，以原生链接在当前标签页跳转；不再显示音乐、性能开关或挂载性能浮层。S 快捷键仍控制背景音乐。
